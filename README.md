# Ship Accident Analysis

## Purpose
This repository contains a descriptive analysis of ship accident
data for SRM 611. It includes data preparation, summary statistics,
frequency tables, and plots exploring accident occurrence,
service exposure, operational status, and construction era.

## Data Source and Access
The dataset, ShipAccidents.csv, was provided through the SRM 611
course Canvas site. It is not included in this public repository
because permission for public redistribution has not been confirmed.

Students with course access can obtain the file from the ship
accident assignment materials on Canvas. Other researchers should
contact the course instructor to request access.

Save the dataset as ShipAccidents.csv in the same folder as the
R Markdown analysis file.

## Repository Files
- Ship accident.Rmd: Source code for data preparation, descriptive
  statistics, tables, and plots.
- Ship-accident.docx: Knitted Word report containing code and results.
- README.md: Project description and reproduction instructions.

## How to Reproduce the Analysis
1. Download the repository files and obtain the dataset.
2. Put ShipAccidents.csv and Ship accident.Rmd in the same folder.
3. Open the R Markdown file in RStudio.
4. Install the rmarkdown and knitr packages if needed:
   install.packages(c("rmarkdown", "knitr"))
5. Click Knit to generate the Word report.
